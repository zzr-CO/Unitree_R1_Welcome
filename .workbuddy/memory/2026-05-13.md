### 关键设计（来自成功案例）
```cpp
// 单次播放：只有在循环模式关闭时才处理
if (!g_loop_on.load()) {
    if (单键触发 && !g_busy) {
        g_busy = true;
        PlaySingleStep(...);
        g_busy = false;
    }
}

// 循环播放：间隔期间内检测停止键
while (waited < GAP_SEC && g_loop_on) {
    检测 ↓+A 停止键;
}
```
