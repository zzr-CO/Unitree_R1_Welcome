# 宇树 R1 — 遥控器展厅接待程序 使用说明

> **版本**：v3.0 | **日期**：2026-05-20 | **文件**：`r1_show_control_dual_voice.cpp` （双音色PCM版）

---

## 1. 程序概述

这是一个基于**宇树遥控器**控制的展厅接待程序。通电即待机，遥控器一键启动/停止。支持**双音色**切换（原始普通话 + 东北话）。

### 核心功能

| 模式 | 按键组合 | 功能 |
|------|---------|------|
| **循环播报** | **↓ + A** | 语音播报同步手臂动作，4段循环 |
| **单次播放** | **← + A/B/X/Y** | 分别播放对应话术+动作（不循环） |
| **切换音色** | **SELECT** | 切换原始音色 ↔ 东北话音色 |

- 循环播报：4段播完自动回到第1段，再次按下 **↓+A** 停止
- 单次播放：按下后播放对应话术，完成后自动停止
- 断电重启后**自动运行**（通过 systemd 开机自启）
- 遥控器通过**无线**与机器人通信，无需网线
- **日志功能**：程序输出同时写入 `/var/log/r1_show_control.log`，方便排查问题

## 5. 操作方法

### 5.1 循环播报模式（↓ + A）

1. 按下 **↓ + A** → LED 变**绿色**，机器人开始播报并执行对应手臂动作
2. 每段话播报时长取决于 PCM 文件长度，间隔 2 秒后自动下一段
3. 4 段话术播完自动循环
4. 再次按下 **↓ + A** → 停止，手臂复位，LED **熄灭**

### 5.2 单次播放模式（← + A/B/X/Y）

| 按键 | 话术 | 动作 |
|------|------|------|
| **← + A** | 早上好呀！新的一天元气满满... | 高举挥手(26) |
| **← + B** | 清晨问好，早安加持！... | 脸部挥手(25) |
| **← + X** | 早上好！迎着晨光上班... | 手放胸口鞠躬(33) |
| **← + Y** | 早安～新日新起点... | 右手举起示意(23) |

- 按下对应按键 → LED 变**绿色**，播放对应话术+动作
- 播放完成后 LED 自动**熄灭**

### 5.3 切换音色（SELECT）

| 音色版本 | 说明 |
|---------|------|
| 原始音色 | 标准普通话女声 |
| 东北话音色 | 辽宁东北话女声 (Xiaobei) |

- 按 **SELECT** 键 → 当前音色在两种版本间切换
- 切换后立即生效，下次按 ←+A/B/X/Y 即用新音色
- 在循环模式中也可切换音色

### 5.4 安全退出

程序运行时按 **Ctrl + C** → 手臂复位 → LED 熄灭 → 程序退出

> **注意**：如果用了开机自启动，程序由 systemd 管理，手动退出后会被自动重启。

| 状态 | LED颜色 | 含义 | 触发方式 |
|------|---------|------|----------|
| **空闲待机** | ⚫ 熄灭 (0,0,0) | 等待遥控器指令 | 程序启动 / 循环停止 / 单次播放完成 |

```

    ↓
[⚫ 熄灭 - 空闲待机]
    │
    ├─ 按 ↓+A ──→ [🟢 绿灯 - 循环播放中]
    │                    │
    │               (4段循环)
    │                    │
    │               按 ↓+A ──→ [⚫ 熄灭 - 空闲待机]
    │
    └─ 按 ←+A/B/X/Y ─→ [🟢 绿灯 - 单次播放中]
                          │
                     (播放完成)
                          │
                          ↓
                   [⚫ 熄灭 - 空闲待机]
```

| 想知道的 | 看什么 |
|---------|--------|
| 程序是否在运行？ | LED是否为绿色（播放中）或查看日志 |
| 程序是否正常响应遥控器？ | 按 ←+A，看LED是否变绿再熄灭 |
| 程序是否崩溃？ | LED是否熄灭 |
| 循环是否在播放？ | LED是否为绿色 |

## 7. 遥控器休眠问题 ★ 重要

### 现象

程序运行一段时间后，按 **↓+A** 机器人无反应。

### 原因

宇树遥控器有**自动休眠机制**，无操作约 5~10 分钟后自动断电，DDS 消息停止发送，程序无法接收指令。

### 解决方法

| 方法 | 操作 |
|:----:|---------|
| **唤醒遥控器** | 按遥控器任意键唤醒，再试 ↓+A |
| **关闭自动休眠** | 查阅遥控器说明书，部分型号支持长按 `start+select` 关闭自动休眠 |
| **更换遥控器电池** | 低电量也可能导致通信不稳定 |

### 网线说明

- 网线仅用于**电脑 SSH 烧录/调试程序**
- 程序运行后**可拔掉网线**，遥控器通过无线与机器人通信
- 遥控器休眠与网线无关

## 8. 开机自启动管理

### 8.1 服务管理命令

```bash
# 查看运行状态
sudo systemctl status r1-show

# 停止运行
sudo systemctl stop r1-show

# 启动服务
sudo systemctl start r1-show

# 重启服务
sudo systemctl restart r1-show

# 查看是否启用开机自启
sudo systemctl is-enabled r1-show
# 应该输出：enabled

# 取消开机自启
sudo systemctl disable r1-show

# 重新启用开机自启
sudo systemctl enable r1-show
```

### 8.2 查看日志

程序日志同时输出到两个位置：
1. **程序日志文件**：`/var/log/r1_show_control.log`（推荐查看这个）
2. **systemd 日志**：`sudo journalctl -u r1-show`

#### 查看程序日志文件

```bash
# 查看实时日志（推荐）
tail -f /var/log/r1_show_control.log

# 查看最后50行
tail -n 50 /var/log/r1_show_control.log

# 查看今天的所有日志
grep "$(date +%Y-%m-%d)" /var/log/r1_show_control.log

# 搜索错误信息
grep -i "error\|warn" /var/log/r1_show_control.log
```

#### 查看 systemd 日志

```bash
# 查看最近50行日志
sudo journalctl -u r1-show -n 50 --no-pager

# 实时跟踪日志（类似 tail -f）
sudo journalctl -u r1-show -f

# 查看今天的所有日志
sudo journalctl -u r1-show --since today --no-pager
```

#### 日志文件管理

- **自动轮转**：日志文件由 `logrotate` 管理，保留最近7天，自动压缩旧日志
- **配置文件**：`/etc/logrotate.d/r1-show`
- **手动轮转**：`sudo logrotate /etc/logrotate.d/r1-show`

### 8.3 验证开机自启动

```bash

# 第2步：等待重启完成（约30-60秒），SSH重新登录
```

## 10. 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 编译报 "file not found" | 不在 SDK 根目录 | `cd /home/unitree/unitree_sdk2-1.0` |
| 运行报 "语音不可用" | 语音服务未启动 | 检查机器人语音服务状态 |
| 运行报 "手臂不可用" | 手臂服务未就绪 | 不影响语音功能，仅无动作 |
| **按 ↓+A 无反应** | **遥控器自动休眠** | **按任意键唤醒遥控器，见第7章** |
| LED 不亮 | 部分机型无 LED 硬件 | 不影响语音和动作功能 |
| 开机后程序未启动 | systemd 问题 | 查看日志：`tail -f /var/log/r1_show_control.log` |
| 动作执行报错（非0返回码） | 动作ID不支持或机器人状态不对 | 确认动作ID在当前机型上可用，机器人需处于站立状态 |
| 修改代码后不生效 | 没有重新部署 | 运行 `./deploy_r1.sh` 重新部署 |
| **如何排查程序是否正常运行？** | **不确定程序状态** | **查看日志文件：`tail -f /var/log/r1_show_control.log`，看是否有新日志输出** |
| **程序假死（无响应）** | 循环播放期间停止键无反应 | 重启服务：`sudo systemctl restart r1-show` |

```bash
#    show_01.pcm  show_02.pcm  show_03.pcm  show_04.pcm
```


## 14. 完整清理流程（删除所有痕迹）★ 新增

### 14.1 清理脚本（在机器人上执行）

> **注意**：清理脚本**不会删除音频文件**，如需删除请手动操作（见 14.3 节）。

```bash
#!/bin/bash

# 6. 重载 systemd 并验证
echo "[6/6] 重载 systemd..."
sudo systemctl daemon-reload

echo ""
echo "=== 清理完成，开始验证 ==="

# 验证
if [ -f /etc/systemd/system/r1-show.service ]; then
    echo "✗ 服务文件仍存在"
else
    echo "✓ 服务文件已删除"

if [ -f /usr/local/bin/r1_show_control ]; then
    echo "✗ 可执行文件仍存在"
else
    echo "✓ 可执行文件已删除"

if [ -f /var/log/r1_show_control.log ]; then
    echo "✗ 日志文件仍存在"
else
    echo "✓ 日志文件已删除"
fi

if [ -f /etc/logrotate.d/r1-show ]; then
    echo "✗ 日志轮转配置仍存在"
else
    echo "✓ 日志轮转配置已删除"
fi

# 检查是否还有相关进程
```
